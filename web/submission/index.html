第一次运行 · 模型服务与存档说明

密钥由本机服务端读取，不放入浏览器。将源码根目录 .env.example 复制为 .env.local，按 README 填写。

  • QWEN_AGENT_API_KEY：小禾真实对话、规划与质检。
  • TOAPIS_API_KEY：可选的设计图生成。
  • AHOLO_API_KEY：可选的 3D 资产生成。

缺少生成密钥时，仍可使用已有物件布置。缺少对话密钥时，小禾会明确说明无法连接。新增付费制作保留确认步骤。保存需要同时保留浏览器网站数据与服务端数据目录。

当前真实共创范围为首个相邻扩建地；完整家园其他区域用于探索与展示。邻居为持久化 NPC。

提交包不含预录演示影片。完整家园展示提供可操作的现成场景；真实小禾对话和布置需要按上述说明配置服务。工程中的故事演示使用预设流程，不能作为实时生成能力的证明。
